# Mukul — research portfolio

Static academic portfolio at https://mukul-quantum-researcher.github.io/.

Serve this directory with `python -m http.server 8000`, then visit http://localhost:8000. There is no build step.

Project pages, CV and figure provenance are kept with the site. The working folder retains original-resolution images in `assets/originals`; web images use WebP. Only the small social-preview original is included in the published repository. The full reports provide the source context. Research and simulation limitations are described on each project page.

The original report downloads retain their contents. Source references for PDF images are listed in `assets/figure-sources.json`. The prior application-information site remains in Git history.
