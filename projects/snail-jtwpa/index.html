Parametric amplification · Work in progress

SNAIL JTWPA parameter design

A consistent starting point for junction parameters, line impedance and dispersion—before scaling the nonlinear circuit.

Code & documentation

What I am studying

This project explores a DC-flux-biased SNAIL travelling-wave parametric amplifier using three-wave mixing. The immediate goal is to establish a consistent parameter model before trusting a large pumped nonlinear simulation.

Python parameter workflow

The notebook finds stable SNAIL operating points, evaluates the potential’s Taylor coefficients, maps the dimensionless model to junction and cell parameters, and checks discrete Bloch dispersion, cold phase mismatch and finite loop-inductance sensitivity.

The baseline candidate uses three large junctions, a small-to-large critical-current ratio of 0.29 and a flux bias near 0.4089 Φ₀. A 145 pH cell inductance and 58 fF shunt capacitance give a nominal 50 Ω line. These values are provisional model parameters.

Current status

The Python parameter-design stage is the usable entry point. The accompanying Julia/JosephsonCircuits notebook is a work in progress: the supplied run stopped at a component-definition error, and the small-cell nonlinear validation steps remain unfinished.

Earlier trials contain convergence warnings and inconsistent gain estimates. They are not used here as evidence of amplifier performance. The revised baseline also differs from the earlier periodically loaded line: it does not introduce a resonant phase-matching network unless pumped validation shows one is needed.

Next checks

First reproduce the small-signal inductance of a single SNAIL, then the unpumped dispersion of a short line, then signal–idler conversion and nonlinear phase mismatch. Scaling toward hundreds of cells should follow those checks. No validated gain, noise performance or fabrication-ready layout is claimed.
